## What it is

You already decided to take a pattern file to a copy shop.
You need one page the clerk can read: print at 100%, which
paper, which file, which size layer, and do not cut.

This download is:

- A one-page drop-off slip with blanks for scale, paper,
  file name, layers, trim, and pickup
- How-to: fill it at home, say 100% at the counter, measure
  the test square before you cut fabric
- Limits you should read before you treat a filled page as
  a shop that must take the job
- One fictional filled example (Maple Court studio, labeled
  fictional)
- A printable PDF of the slip page

You write the file you actually have. You circle 100% /
actual size. You hand the page to the clerk. Cutting is later.

## What it is not

- Not a sewing pattern
- Not a tiled-PDF joiner (it does not combine pages)
- Not a test-square pack (no 4 inch or 10 cm squares inside)
- Not the print-at-home vs copy-shop chooser (that page is
  where to print; this page is what you hand the clerk)
- Not a copy shop and not a print order a shop must accept
- Not a price list for ink, paper, or large-format sheets
- No garment fit is guaranteed

There are no testimonials on this page because we are not going
to invent them.

## Who it is for

A home sewist who already decided to take a file to a copy
shop, can write 100% / actual size on a slip, and will measure

## Who it is not for
